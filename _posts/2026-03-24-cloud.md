## How Cloud and High Performance Computing transform science at NOAA Fisheries

 Cloud and High Performance Computing is transforming science at NOAA Fisheries by allowing scientists to access additional computing power. Some recent successes using cloud or high performance computing at NOAA Fisheries include:

 - [Using satellite imagery, AI, and cloud computing to detect whales](https://www.fisheries.noaa.gov/new-england-mid-atlantic/science-data/geospatial-artificial-intelligence-animals)
 - [Using HPC to speed up stock assessment model runs](https://moshima-pifsc.github.io/NSASS-HTC-HPC-Computing/)
 - [Creating new ocean modeling products and providing them to the public](https://www.fisheries.noaa.gov/feature-story/noaa-launches-new-ocean-modeling-system-west-coast-and-alaska)
 
We expect more success stories to come in the future, as NOAA Fisheries is [moving to the cloud](https://sites.google.com/noaa.gov/inside-fisheries-it/information-technology/modern-mission-delivery/cloud-migration-hub) (link accessible to NOAA staff). Cloud and High Performance Computing Resources are already available at NOAA Fisheries for staff.

## What is cloud computing?

From Wikipedia: “Cloud computing is the on-demand availability of computer system resources, especially data storage and computing power, without direct active management by the user. The term is generally used to describe data centers available to many users over the Internet.”

[Cloud computing](https://nmfs-opensci.github.io/CloudComputingSetup/content/intro/intro.html#working-in-the-cloud) is [scalable](https://cloud.google.com/discover/what-is-cloud-scalability) for the user, an advantage over on-premise computing resources.

## Cloud security

Cloud services used at federal agencies need to be secure. [FedRAMP authorized services](https://www.fedramp.gov/) help lower the barrier to adoption by federal agencies, though individual agencies ultimately determine security approval of cloud services. Not all cloud services are [in scope for FedRAMP](https://www.fedramp.gov/docs/authority/scope/).

## Google Workstations at NOAA Fisheries: A cloud computing option

On-premise resources are being migrated to the cloud. As part of the [migration](https://sites.google.com/noaa.gov/inside-fisheries-it/information-technology/modern-mission-delivery/cloud-migration-hub), Google workstations are available for NOAA Fisheries staff for cloud computing.

>Google Cloud Workstations is a managed service that provides a flexible, self-serve platform. Because Google handles the underlying infrastructure, the Fisheries Cloud Program team can focus on creating tailored environments, managing access, and ensuring security, reducing setup costs and promoting a faster "time to science" for users.

Request access or learn more in the [Cloud Compute Accelerator Documentation](https://docs.google.com/document/d/1nziPdPULoRWOYQ9WKzISNUgJvANACvfYpFr1z3Ro2Bc/edit?tab=t.0) (must be logged into NOAA email to access document).

For self-guided training, see materials from the [NOAA Fisheries Google Cloud Workstations Workshop](https://nmfs-opensci.github.io/CloudComputingSetup/). Thanks to NOAA Fisheries early adopters who have documented [additional tips and tricks for using Google Workstations](https://github.com/nmfs-opensci/CloudComputingSetup/).

## What is High Performance Computing at NOAA Fisheries?

At NOAA, High Performance Computing (HPC) refers to resources available through the [High Performance Computing and Communications (HPCC program)](https://www.noaa.gov/information-technology/hpcc). NOAA HPC includes both cloud computing and on-prem resource options. This option is worth exploring for workflows with high computational needs.

For NOAA Fisheries staff interested in using NOAA HPC resources, [contact the FIT](https://nmfs-ost.github.io/noaa-fit-resources/contact/) to learn more or submit a request to use NOAA HPC resources. Individual line office within NOAA must put in requests for project resources and HPC allocation must be approved through the allocation committee.

## Cloud data management

### Archiving

NOAA's [NCEI](https://www.ncei.noaa.gov/archive) provides archive services for much of the data from NOAA Observing Systems. Other options include [NOAA approved data repositories](https://wpo.noaa.gov/wp-content/uploads/2025/08/NOAA-ADRs_DGCFinalDraft_June2025.pdf).

### Cloud Hosting

Generally keeping data “close to computation” will increase the speed and reduce cost of cloud resources. For example, keeping a data bucket in the same project as the virtual machine used for computation is suggested if computation is a big part of the workflow.

NOAA Fisheries staff increasingly have access to Google Cloud Platform (GCP) data buckets, which have flexible permissions. Put in a ticket with your office's IT support to learn more about what is available at your office.

For public data sets the [NOAA Open Data Dissemination Program](https://www.noaa.gov/information-technology/open-data-dissemination) also provides a pathway for cloud hosting of public data.
